# Project Overview

This project is a website for Kwa Shumilensizwa, a restaurant that specialises in traditional Kasi-inspired meals.

The aim is to give the restaurant its own online presence where customers can learn about the business, view the menu, make enquiries, find the restaurant and access online ordering.

# Website Goals

The main goals of the website are to:
Improve the restaurant's online presence.
Make the menu easy to access.
Help customers find contact and location information.
Provide a simple enquiry and ordering process.
Promote the restaurant's food and brand.
Create a website that works well on mobile and desktop devices.
Target Audience

**The website is aimed mainly at:**

Durban residents.
Existing customers.
Students and young adults.
Families and groups.
Visitors interested in local South African food.
Customers who prefer finding restaurants and ordering online.

Design

The design uses a warm and colourful style to represent the restaurant's food and Kasi identity.

Colours
Orange/Red: Main buttons and highlights.
Yellow: Secondary accents.
Red: Headings and food categories.
Deep Purple: Navigation and footer.
Lime Green: Background sections.
Typography
Poppins: Headings.
Open Sans: Body text.

The website follows a mobile-first approach with clear navigation, readable text, accessible buttons and optimised images.
